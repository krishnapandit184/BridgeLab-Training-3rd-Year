# JavaScript Assignment 5

Separate ES6+ JavaScript files for all 9 questions.

## Run
Use Node.js from this directory, for example:

```bash
node Q1_CallbackFlow.js
```

Repeat with the filename for each question.

## Files
1. Q1_CallbackFlow.js — callbacks
2. Q2_ApplyOperation.js — callbacks and map
3. Q3_ArrowFunctionThis.js — arrow function `this`
4. Q4_CarPrototype.js — constructor and prototype method
5. Q5_PersonStudentInheritance.js — prototype inheritance
6. Q6_PersonFacultyProfessor.js — multilevel prototype chain
7. Q7_ClosureMultiplier.js — closures
8. Q8_CustomMyMap.js — custom array prototype method
9. Q9_ClassInheritance.js — ES6 classes, extends, and super
