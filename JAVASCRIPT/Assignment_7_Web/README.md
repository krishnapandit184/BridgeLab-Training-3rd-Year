# Assignment 7 — HTML, CSS, and Core JavaScript

Each question has its own folder with `index.html`, `style.css`, and `script.js`.
Open the relevant `index.html` file in a browser to test the interactive assignment.

## Questions
1. Dynamic Product List Manager — event delegation and inline editing
2. Live Character Counter — 100-character limit and warnings
3. Multi-Step Form — step-by-step validation
4. Theme Switcher — `setAttribute()` and `data-theme`
5. Image Gallery — modal preview and `stopPropagation()`
6. Student Table Filter — case-insensitive input filtering
7. Mouse Coordinates — mouse movement and double-click markers
8. Custom Dropdown — capturing-phase outside-click handler
9. Form Submit Blocker — `preventDefault()` and live errors

The image gallery uses Picsum image URLs and therefore needs an internet connection for its images.
